# Логирование

Каждая команда пишет в свой файл в `Documents/AutoBIMFusion/Logs/`:

| Команда | Файл |
|---|---|
| `MERGEDWG` / `MERGEDWG_BATCH` | `mergedwg-YYYY-MM-DD.log` |
| `QUICKPDF` | `quickpdf-YYYY-MM-DD.log` |

По умолчанию записываются предупреждения и ошибки (`Warning`, `Error`, `Fatal`),
а также краткий итог команды (`Information`). Сохраняются время, идентификаторы
процесса и потока, сообщение и полное исключение со стеком вызовов.
Геометрические дампы и пошаговые детали в обычный лог не попадают.
Это действует и для Debug-сборок. Сообщения лога — на английском.

Итог команды сохраняется независимо от `LOG_LEVEL`: для слияния — результат
обработки файлов, число успешных, пропущенных и неудачных файлов, путь сохранения
и длительность; для QuickPDF — число рамок, устройство и папка вывода.
Ошибка обработки файла даёт итог уровня `Warning`; успешная обработка или пропуски —
`Information`. Отмена выбора папки в лог не пишется.

Для подробной диагностики задайте `LOG_LEVEL=Debug` перед запуском AutoCAD.
Допустимы уровни Serilog: `Verbose`, `Debug`, `Information`, `Warning`, `Error`,
`Fatal` (регистр не важен). Пустое или некорректное значение означает `Warning`.
Уровень читается при первом создании логгера команды; после изменения перезапустите AutoCAD.

`AUTOBIMFUSION_DIAG=1` включает отдельный файл `merge-diagnostics-YYYY-MM-DD.jsonl`
без повышения уровня обычного лога. `LOG_LEVEL=Debug` или `Verbose` также включает
эти события. При выключенной диагностике JSON-события не сериализуются и не пишутся.
После диагностики удалите переменные, чтобы вернуться к краткому логу.
