# Логирование

По умолчанию в `Documents/AutoBIMFusion/Logs/merge-YYYY-MM-DD.log` записываются
только предупреждения и ошибки (`Warning`, `Error`, `Fatal`). Сохраняются время,
идентификаторы процесса и потока, сообщение и полное исключение со стеком вызовов.
Сообщения загрузки, успешного завершения, геометрические дампы и статистика
в обычный лог не попадают. Это действует и для Debug-сборок.

Для подробной диагностики задайте `LOG_LEVEL=Debug` перед запуском AutoCAD.
Допустимы уровни Serilog: `Verbose`, `Debug`, `Information`, `Warning`, `Error`,
`Fatal` (регистр не важен). Пустое или некорректное значение означает `Warning`.
Уровень читается при первом создании логгера; после изменения перезапустите AutoCAD.

`AUTOBIMFUSION_DIAG=1` включает отдельный файл `merge-diagnostics-YYYY-MM-DD.jsonl`
без повышения уровня обычного лога. `LOG_LEVEL=Debug` или `Verbose` также включает
эти события. При выключенной диагностике JSON-события не сериализуются и не пишутся.
После диагностики удалите переменные, чтобы вернуться к краткому логу.
