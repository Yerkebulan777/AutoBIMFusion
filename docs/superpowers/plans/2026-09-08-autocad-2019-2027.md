# AutoCAD 2019–2027 compatibility

**Goal:** Build the existing plugin for each AutoCAD release from 2019 through 2027.

**Architecture:** Keep the three projects and one source tree. Select the host SDK,
framework and exact autoload series centrally by DebugAxx/ReleaseAxx configuration.
Use .NET Framework 4.7 for 2019–2020, 4.8 for 2021–2024, .NET 8 for 2025–2026
and .NET 10 for 2027. Legacy-only compatibility dependencies preserve modern source APIs.

**Constraints:** x64; stable AutoBIMFusion.bundle, AutoBIMFusion.dll and
./Contents/AutoBIMFusion.dll; no host runtime DLLs in output; no changes to AutoCAD
threading or document locking. One installed bundle targets one selected year.

## Verification notes

- All 36 Debug/Release desktop/headless configurations built and bundle manifests
  and dependency lists were checked with `tools/Test-AutoCADBuildMatrix.ps1`.
- Standalone compatibility tests cover net47, net48, net8.0-windows, net10.0-windows.
  Legacy tests deliberately disable executable binding redirects.
- AutoCAD 2019 Core Console loaded the plugin, ran MERGEDWG_BATCH, saved a DWG,
  and reopened it to verify model entities. Serilog produced its file log.
- Runtime testing exposed a desktop-only DocumentCollection.Add call in headless
  document selection and legacy BCL binding mismatches. Headless now requires the
  existing empty unnamed drawing; a module initializer registers a bounded legacy
  assembly resolver before commands execute.
- The host smoke test is repeatable with `tools/Test-AutoCADHost.ps1`.
- AutoCAD 2020–2027 runtime sessions and the desktop Ribbon were not exercised.

## Stability review follow-up

- Desktop/headless outputs, intermediate files and NuGet assets are isolated for
  every year, including net47/net48. The matrix checks that headless compilation
  does not overwrite the desktop DLL.
- Bundle publication is shared by MSBuild and the manual installer. It stages and
  hashes the copy before replacing the directory, keeps a backup for rollback,
  and serializes installers. Tests cover incomplete sources and locked DLLs.
- Manual installation always builds desktop first. Headless build and clean do
  not change the installed desktop bundle.
- Host tests use Core Console `/isolate`, load the packaged DLL, reject a
  mismatched host version and require a log record containing the unique run path.
  AutoCAD 2019's original SECURELOAD=1 was restored after the earlier test; the
  isolated smoke test leaves it unchanged.
